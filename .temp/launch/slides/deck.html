How it works

Install once. Students get a token, not AWS access.

You, the teacher

One command installs everything in your own AWS account.

Teacher page, student sites, and the features you choose to switch on.

Your students

Class Hosting Platform3 / 8
For the teacher

Create a token. Share it.

  • One token per studentshown once, with a ready-made message to send them
  • You choose how long it laststhen extend it, take the site offline, or revoke it

Tokens are stored only as hashes. A lost one is replaced, never recovered.
