# Prompts to start with

Paste one into your AI assistant. Edit the idea to be yours. The assistant already knows the platform's rules from `AGENTS.md`.

## Build something

- *"Make a quiz app: the user picks a topic, the backend asks the class AI for 3 multiple-choice questions, and the page shows them one by one with a score."*
- *"Make a study buddy chat: a text box and a conversation list. Each message goes to my backend, which asks the class AI to explain it simply."*
- *"Make a recipe helper: the user types ingredients, the AI suggests a dish. Keep the last 5 suggestions in localStorage."*
- *"Make a to-do list that is stored in localStorage, with a button 'Suggest next task' that asks the class AI."*
- *"Turn my idea into this platform's structure: [describe your idea]. Ask me questions first if something is unclear."*

## Improve what you have

- *"Show friendly messages when the AI allowance is used up or the AI is switched off."*
- *"Make the page look good on a phone."*
- *"Explain what each file in backend/ and frontend/src/ does, in plain words."*

## Before you push

- *"Run npm run check and fix every problem it reports."*
- *"Review my changes for leaked keys or tokens."*

## If something fails on GitHub

- *"This GitHub Action failed. Here is the red message: [paste it]. Fix the project."*
